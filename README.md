## 这个项目是干什么的

**一句话：把图片变成 tag 的「弹药库」，让 ComfyUI 抽卡越抽越自由。**

![看板：按来源筛选 + 安全模式](docs/images/home.png)

### tag 从哪来

两条路：一是**自己收集的图**——网上存的、别人分享的，AI 会自动「看图说话」反推出一套标签（WD14 反推）；
二是**自己用 AI 生成的图**，本来就带着生成时的标签。有意思的是：同一套标签抽十次卡能出十张不同的图——
同样的「蓝发、校服、教室」，姿势构图各不相同。挑出满意的那张再反推一次，就得到一套「进化过」的新标签。
这样一轮轮滚下去，标签库像滚雪球一样越滚越大。

### 导出：按需组合，不想要的 ban 掉

能导出的标签组合越丰富，抽卡的选择余地就越大。比如想要「举剑的骑士」，凭空想词很干瘪；
但库里存了二十张不同角度的骑士图，挑三张各导一份混着用，出来的图就丰富得多。
而且导出可以按需组合：导「萨菲娅」的标签时总带着「闭眼」，这次想画睁眼的，把 `closed_eyes` ban 掉，
导出时自动过滤；想要全身立绘就把「特写」类剔掉，想要大脸就剔「全身」，一个开关的事。

### 角色库与购物车：组队导出去抽卡

工具认得出每张图上画的是谁，自动把所有图按角色归好类——相当于白得一座按角色分好类的图库。
看图时看到喜欢的角色，点一下加进「购物车」，攒出一支想要的队伍：想画双人图就把两个角色丢进购物车，
一键导出成一个角色组文件，扔回 ComfyUI 直接抽卡。攒好的队伍还能**存成清单**，
下次在「我的清单」里一键切回来，不用重新一个个点。
**不同的角色组合 × 不同的标签组合，两个维度一乘，可能性就爆炸了。**

![系列浏览：作品 → 角色](docs/images/series.png)

![角色购物车：批量入车、一键导出角色组](docs/images/cart.png)

### 顺手的图片管理

全屏翻页看图、批量移动归档、按角色一键筛选，都是围着「服务画图」转的。

![大图预览：标签全带中文翻译](docs/images/lightbox.png)

**第一次登记图片文件夹**：扫描页 → 右上角「🗄️ 来源管理」→ 添加即登记 + 扫描。
把某目录「移出」只是注销用途（可逆，图还在库里），「彻底清除」才会删库里的记录。

![来源管理：文件夹当频道，开关即用途](docs/images/sources.png)

## v2.3 系列最值得先试的几件事

1. **在系列里一路点标签下钻**：全部系列 > 蔚蓝档案 > airi_(band) > breasts。
   每层顶部都有路径栏，点最左边的箭头退一层，会把你当时正在看的那张大图原样拉回来 ——
   不是关掉重来。看板 / 系列 / 扫描里点标签是**就地翻一层**，不换页、顶部 tab 不动；
   标签页还能继续往下叠，每层独立记住自己的筛选和勾选。
2. **查重面板当成图片流来用**：滚到底自动加载下一批，右下角有回到顶部；
   点开大图能跨组连着看，退出时自动滚回刚才那一组。
   「保留哪一张」改成下拉筛选项（画师信息 / 创建时间 / 文件大小 / 分辨率 / 图内元数据 / 文件名特征）；
   误报的组可以「删记录」**永久拉黑**（只删记录不删图），底部还有一键全部恢复。
3. **库内命中：找「最像这张图」的图**：光箱里看到喜欢的构图，点「库内命中」徽章，
   剔除角色/机位词后按重合度给全库打分，用来找同款构图、同套服装；0 命中时会降级显示最接近的一批。
   结果是就地叠一层，退出原路返回。
4. **Ctrl+滚轮缩放全站通用**：看板、标签页、收藏、系列根页、扫描页的图片网格，
   以及光箱、查重面板、系列/角色卡片都能缩放。底部有百分比徽标，停手淡出，点一下回到 100%。
5. **看板可以只看 ComfyUI 生成的图**：按图内嵌元数据的来源筛，比按文件名猜靠谱；
   刚入库还没读到来源的图会在后台补读。
6. **安全模式有了取反**：正常安全模式把敏感图藏起来；新增的「不安全模式」正好相反 ——
   只显示命中敏感标签的图，用来集中审一遍需要清洗的部分。

## 几个真正好用的细节

- **标签全带中文翻译**：内置 1.6 万条翻译 + 3,400 条人工分类，界面上所有标签都显示成「蓝发」「教室」，选词零门槛。
- **搜索框会「组词」**：敲逗号（中英文都行）把当前词定格成胶囊，接着联想下一个词；下拉里的「全选」
  把当前词匹配到的标签一次全加入（打「发」→ 全部发色/发型，配「any 任一命中」就是全都要）。
  方向键在联想列表里移动时自动跟随滚动；拼音组词中回车不会误触发搜索。
- **每个页面都有安全模式开关**：一键把不健康的图全藏起来，看板 / 收藏 / 购物车 / 扫描 / 系列页页都有，
  连**封面缩略图**也会换成安全范围内的图（没有合适图就显示默认占位封面）；
  标签页里连**敏感词条**也会一并藏掉。被藏空了还能手动「继续拉下一批」。
- **光箱能读图内元数据**：除了标签库，还能切到「图内元数据」看这张图生成时带的原始词；
  词条会先去标签库匹配 —— 命中的显示库内图片数、点击直达，没命中的灰化、点了只复制不硬跳。
- **标签页更好翻**：「隐藏已ban」开关默认把已 ban 的词条藏起来（点一下显示，记忆在本地）；
  列表滚到底自动加载，不用翻页。
- **图片文件夹当「频道」管理**：每个文件夹一个按钮，点一下只看这个文件夹的图；
  移出来源就从界面消失（文件不动，可逆）。扫描页还支持 8 种排序（文件名 / 子文件夹 / 修改时间 / 大小 / 标签数），
  翻页只渲染当前页，大文件夹也不卡。
- **整个作品的角色名单是现成的**：按「作品 → 角色」两级组织，支持中文搜索、批量入购物车；
  角色卡右上角能收藏，菜单里能 ban（含二次确认和「不再提示」）。
- **封面可自定义也懂安全模式**：系列卡 / 角色卡悬停出现 🖼，从这组图里挑一张当封面（挑完随时可恢复自动）；
  还能直接从 Danbooru 在线搜图下载当封面，支持后台批量拉取。
  没自定义时封面自动避开安全模式下看不见的图，🛡 开关一切列表跟着刷新；扫描夹删图/移图后封面会自动换一张，不会变白块。
- **批量选择**：看板、标签图片页、扫描页悬停出现勾选框，长按也能进选择模式；
  支持 Ctrl+点击、Shift 区间选、Ctrl+A、Delete、Esc，操作条是底部居中的浮动条。
- **多套替换规则按需切换**：给不同导出目的各配一套规则（给 ComfyUI 补质量词、传站点的清洗版、
  角色表专用……），导出时在下拉里挑；现有那份规则自动是「默认组」，行为一点不变。
  规则支持社区写法 `(tag:1.2)`，chip 上能点开调权重。
- **反推模型可选**：设置里能选 `auto / v0.9 / v1.0`，v1.0 还有 336 / 672 两档快速模式；
  无角色、无系列的图可以单独补识别，只追加角色/系列，不动已有标签。
- **小功能**：右键复制图片 / 用其他程序打开（程序清单可在设置里管理）、收藏 + 备注、
  自动导出带倒计时与预设、8 种排序、启动画面 + 冷启动兜底、全程本地运行不上传。

## 快速开始

**方式一：安装包（推荐给使用者）** —— 到 [Gitee Releases](https://gitee.com/klanf/tag-viewer/releases)
下载最新版（GitHub Releases 暂未启用，源码镜像见 [GitHub 仓库](https://github.com/klanf/tag-viewer)）：

- **引导安装器**（`TagViewer-引导安装器-vX.Y.Z.exe`，<1MB）：双击后自动从 Release
  拼包安装，不用手动下 110MB 大文件；
- 或直接下完整安装包 `TagViewer-Setup-x.y.z.exe`。

装完即用。翻译（1.6 万条）与韦林人工分类已内置，WD14 标签词表 CSV 也随包自带 ——
**首次点「反推」时只剩推理环境要下载**（Python + onnx 模型，约 1.4 GB，支持断点续传，
右下角有进度卡），之后全程本地推理不联网。

**方式二：绿色分发包（解压即用）** —— 解压，双击「启动看板.bat」（或 启动看板.vbs，不弹黑框），
什么都不用装。包用 `npm run pack:green` 打出来，见 `scripts/pack-green.mjs` 头部说明。

**方式三：从源码跑** —— 双击启动脚本：

```bat
双击「启动看板.bat」          :: 或 启动看板.vbs（不弹黑框）
```

首次在这台机器之外的环境部署时：

```bat
npm install        :: 自动把本机已有的 Electron 运行时硬链过来，不重新下载 100+MB
npm run build      :: 构建前端到 dist/
npm start          :: 启动（等价于双击启动脚本）
```

> `npm install` 的“复用本机已有运行时”这一步靠 `scripts/local-config.mjs` 找候选目录。
> 找不到就会退回官方下载；也可以自己写一份 `local.config.json`（模板见
> `local.config.example.json`）把本机路径填进去，该文件不进仓库。

## 路径与数据目录

### 数据目录

| 优先级 | 来源 | 说明 |
| --- | --- | --- |
| 1 | `settings.json` 的 `dataDir` | 真实设置文件在 `<userData>/settings.json`（Windows: `%APPDATA%\TagViewer\`） |
| 2 | 环境变量 `TV_DATA_DIR` | 适合脚本/多套数据切换 |
| 3 | **与应用同目录的 `data/`**（portable） | 存在且可写就用它 —— **绿色包的数据随包走**（删文件夹即卸载）；仓库开发态同样命中。只由 main.js 开启（`allowPortable`），CLI 工具与测试不受影响；打包态（asar 内）探测失败自动回落 |
| 4 | `<userData>/data` | 以上都没有时的默认值，一定是可写目录 |

数据目录里放什么，按「能不能对外分发」分三类（见 `paths.js` 的
`KNOWLEDGE_FILES` / `USER_FILES` / `DERIVED_FILES`）：

| 类别 | 文件 | 会不会随仓库分发 |
| --- | --- | --- |
| **知识** | `local_translations.json`、`character_library.json`；**翻译 + 韦林人工分类已内置**：构建期由 `scripts/build-translations-db.py` 从 `knowledge/weilin_data(...)` 合并进 `assets/translations.db`（translations 16,558 条 + tag_cats 3,457 条分类），随包分发 | 翻译/分类源数据随仓库分发（来源与授权现状见 `knowledge/README.md`）；另外两份是用户自己的补译/映射，不进仓库 |
| **用户数据** | `export_blacklist.txt`、`user/replace_sets.json`（**替换规则组**）、`export_bg.txt`、`user_meta.json`、`user/user_covers.json`（自定义封面表 —— 值是**本机图片的绝对路径**，所以单独一份）、`cart_history.json`、`folders.json`、`safety_tags.txt`（安全模式的敏感标签集合，两段）、`safety.json`（开关与档位）、`.thumb_cache/` | **绝不出机器** |
| **可再生派生物** | `tags.db`、`scan_cache.json` | 不进仓库。都内嵌本机文件路径，将来若要随包分发必须先从里面**提炼**出纯标签/系列/角色子集 |

数据目录不存在时会自动创建。里面没有任何标签数据时，应用不会崩，而是给出
「还没有登记图片文件夹」的一键引导 —— 就地选一个文件夹登记就能开始（见 `TvBootOverlay`）。

## 已知差异 / 后续可做

| 项 | 现状 |
| --- | --- |
| 打包 | 三种形态齐了：**NSIS 安装包**（`npm run dist`，Gitee Release 主发，配分片 + 引导安装器）、**绿色分发包**三种变体：**点击即用包**（默认，模型+环境全带）、**基础包**（`--variant basic`，不带 1.27GB 模型）、**精简包**（`--variant lite`，模型和 Python 环境都不带，~370MB，适合分发给会自己配环境的人） |
| 数据目录切换 | `electron/core/workspace.js` 支持 `TV_DATA_DIR` 环境变量；UI 里还没有入口 |
| 文件夹库的排序 | 扫描页里的图片有 8 种排序；一级文件夹列表按「最近扫描时间」排（失效的沉底），还没有手动排序选项 |
| 光箱缩放 | Ctrl+滚轮放大后暂时只能看中心区域，还没有拖拽平移 |
| 查重的永久忽略 | 只提供整批「全部恢复」，没有单独列出被永久忽略的组 |
| 就地标签页 | 只在看板 / 系列 / 扫描 / 标签页里生效；收藏与购物车仍走原来的独立标签页 |
